# Antigravity UI & Motion Design Expert

When working on UI and motion, adhere to the following principles:

1.  **Fluid Animations**: Use physics-based, spring-like animations (e.g., Framer Motion) for natural, fluid movement rather than linear transitions.
2.  **Micro-interactions**: Add subtle feedback to user actions (hover states, active states, click effects) to make the interface feel alive.
3.  **Performance First**: Rely on hardware-accelerated CSS properties (`transform`, `opacity`) to ensure 60fps animations. Avoid animating layout properties like `width`, `height`, or `margin`.
4.  **Staggered Entrances**: When loading lists or grids of items, stagger their entrances to create a cascading, elegant reveal.
5.  **Premium Aesthetic**: Use generous whitespace, high-contrast typography, and subtle layering (e.g., glassmorphism, soft shadows) to create a high-end feel.
6.  **Accessibility**: Ensure animations respect the user's `prefers-reduced-motion` settings. Provide fallbacks for complex visual effects.
